Instalación local reproducible en Windows 10 + WSL2 + Docker Desktop: arquitectura, servicios, operación diaria y rutinas de ejecución.Open edX 22.0.2 · Tutor 22.0.2 · Tema Indigo

dniaobjetivoy alcance

Registrar de forma reproducible la instalación local de Open edX para práctica técnica. Docker Desktop aporta el Engine y Ubuntu/WSL2 la consola Linux desde la cual se ejecutan Docker y Tutor: no se instaló un segundo Docker Engine dentro de Ubuntu.

dniamapas dearquitectura

Open edX usa openedx-platform como núcleo (LMS y Studio/CMS), servicios desplegables de forma independiente y micro-frontends React. El backend es Python/Django.
